# henrique.zip

Source code for Henrique de Castilhos' personal landing page, available at [henrique.zip](https://henrique.zip).

## Development

Install dependencies and generate the production stylesheet:

```sh
npm install
npm run build
```

To rebuild the stylesheet while editing:

```sh
npm run tw
```

The site is a plain HTML page styled with Tailwind CSS and deployed through GitHub Pages.
